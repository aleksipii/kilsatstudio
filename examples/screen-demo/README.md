# The Live Demo: a recording on Aino's phone

An English example episode for screen slots. Aino shows Rane her mileage app;
a close-up plays the recording inside the phone's screen slot, and the later
shots hold its saved state.

- `live-demo.kilsat`: generated by `scripts/generate_screen_demo.py`.
- `assets/kilsat-app-demo.mp4`: an original 8 s, 540×1170, 30 fps
  illustrative recording drawn by the same script. It is marked EXAMPLE and is
  not a capture of a real app.

Render (Kokoro installed in the app, FFmpeg/FFprobe from Homebrew):

```sh
cargo build --release -p motion-export --example production_export
target/release/examples/production_export \
  --project examples/screen-demo/live-demo.kilsat \
  --ffmpeg /opt/homebrew/bin/ffmpeg \
  --kokoro-config KOKORO_EXPORT_CONFIG.json \
  --retime-dialogue --deadline-seconds 900 \
  --output NEW_OUTPUT_DIRECTORY
```

The Kokoro export config holds `python`, `runtime_script`
(`services/kokoro-runtime/runtime.py`), `model_config`, `model_weights`,
`voices_directory`, `cache_directory`, `model_version` and `timeout_seconds`.
Speech, mouth timing and artwork are not reviewed for publication.
